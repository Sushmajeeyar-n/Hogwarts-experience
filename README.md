# Hogwarts Experience

An interactive Harry Potter-inspired frontend built with React, TypeScript, Tailwind CSS and Framer Motion.

## Features

- Interactive Sorting Hat
- Animated Spell Casting
- Floating Owl
- Magical Journey Timeline
- Responsive Design
- Smooth Scroll Navigation
- Custom Animations

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite
