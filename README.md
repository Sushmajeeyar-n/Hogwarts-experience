# Hogwarts Experience

An interactive Harry Potter-inspired frontend built with React, TypeScript, Tailwind CSS and Framer Motion.

## Features

- Interactive Sorting Hat
- Animated Spell Casting
- Floating Owl
- Magical Journey Timeline
- Responsive Design
- Smooth Scroll Navigation
- Custom Animations

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite

## Installation

```bash
git clone https://github.com/Sushmajeeyar-n/Hogwarts-experience.git
cd Hogwarts-experience
npm install
npm run dev
```

Inspired by the magical world of Harry Potter.
